DARK CONCORDANCE
================

Deutsch
-------
Ein dunkles Space-Opera-Action-Rollenspiel: drei Helden, vier Akte, ein Prolog, drei Enden.

Starten:  Windows: DarkConcordance.exe.  Linux / Steam Deck: ./DarkConcordance (ohne Steam: aus dem Ordner starten;
          als Nicht-Steam-Spiel in Steam hinzufügen geht auch).
          Der Ordner "assets" muss neben dem Programm liegen. Das Handbuch liegt als Handbuch.pdf bei.

          Windows warnt beim ersten Start ("Der Computer wurde durch Windows geschützt"), weil das Spiel nicht
          signiert ist: "Weitere Informationen", dann "Trotzdem ausführen". Danach fragt Windows nicht mehr.

Steuerung (Tastatur und Maus / Gamepad):
  Laufen            WASD oder Pfeiltasten / linker Stick
  Schießen, Schlag  linke Maustaste / rechter Trigger
  Springen          Leertaste / A
  Ausweichrolle     Strg / Klick des linken Sticks
  Spezialfähigkeit  F / B          Fähigkeiten 2 und 3: R, G / Schultertasten
  Stim              Q / Y          Benutzen, reden: E / X in Reichweite
  Waffe wechseln    T / Steuerkreuz rechts (oder links)
  Ausrichtung halten (Dorra: Schild)  Umschalt / linker Trigger
  Karte M, Inventar I, Charakter C, Fotomodus P, Pause Esc / Start
  Alles lässt sich unter "Optionen > Tastenbelegung" ändern.

Spielstände, Einstellungen und das Spielprotokoll liegen unter %APPDATA%\DarkConcordance (Windows) bzw.
~/.local/share/DarkConcordance (Linux). Vier Speicherplätze; wer das Spiel durch hat, kann den fertigen Helden in einen
neuen Lauf mitnehmen (auch auf einer anderen Schwierigkeit).
Zu zweit (ein Bildschirm, ein zweites Gamepad): Start auf dem zweiten Pad holt einen der beiden anderen Helden dazu,
  noch einmal Start wechselt zum anderen, Ansicht 1,5 s gehalten lässt ihn gehen. Der erste Spieler führt (Gespräche,
  Beute, Türen); der zweite folgt an der Leine und steht nach einem Sturz beim ersten wieder auf.
Ein Leben (Hardcore): beim neuen Spiel unter den Speicherplätzen einschalten. Ein Tod beendet den Lauf, der
  Spielstand bleibt als Erinnerung stehen.
Tagesherausforderung (Titel): jeden Tag ein anderer Held, eine andere Stufe und Tiefe der Tiefen, für alle gleich;
  die Zeiten (mit einer halben Minute je Tod) stehen in challenge.txt im Spielstand-Ordner.

Systemanforderungen: Windows 10/11 oder Linux (glibc 2.35 oder neuer, z. B. Ubuntu 22.04, SteamOS), OpenGL 3.3,
eine Grafikkarte der letzten zehn Jahre; auf dem Steam Deck startet die Grafik auf "Niedrig" mit höchstens 40
Bildern pro Sekunde (im Schnellmenü des Decks den Bildschirm auf 40 Hz stellen; "Sparsam (Akku)" schont ihn mehr).

Stürzt das Spiel ab, liegt ein Bericht unter crashes/ im Spielstand-Ordner; der Titel weist beim nächsten Start
darauf hin.

English
-------
A dark space opera action role-playing game: three heroes, four acts, a prologue, three endings. German and English
(menu, subtitles, voices).

Start:    Windows: DarkConcordance.exe.  Linux / Steam Deck: ./DarkConcordance (or add it to Steam as a non-Steam
          game). The "assets" folder must stay beside the program. The manual comes along as Manual.pdf.

          Windows warns on the first start ("Windows protected your PC") because the game is not signed: "More
          info", then "Run anyway". After that Windows does not ask again.

Controls (keyboard and mouse / gamepad):
  Move              WASD or the arrows / left stick
  Shoot, strike     left mouse button / right trigger
  Jump              Space / A
  Dodge roll        Ctrl / click of the left stick
  Special           F / B          Skills 2 and 3: R, G / shoulder buttons
  Stim              Q / Y          Use, talk: E / X when in reach
  Swap weapon       T / d-pad right (or left)
  Hold the facing (Dorra: shield)  Shift / left trigger
  Map M, inventory I, character C, photo mode P, pause Esc / Start
  Everything can be rebound under "Options > Controls".

Saves, settings and the play log are in %APPDATA%\DarkConcordance (Windows) or ~/.local/share/DarkConcordance
(Linux). Four save slots; a hero who has finished the game can be carried into a new run (on another difficulty
too).
Two players (one screen, a second gamepad): Start on the second pad brings in one of the other two heroes, Start
  again changes to the other one, View held for 1.5 s lets them go. The first player leads (talks, loot, doors); the
  second follows on a leash and gets up again beside the first after a fall.
One life (hardcore): switch it on below the save slots when beginning a new game. One death ends the run, the save
  stays as a memory.
Daily challenge (title): every day another hero, level and tier of the Depths, the same for everyone; the times
  (with half a minute for each death) are kept in challenge.txt in the save folder.

Requirements: Windows 10/11 or Linux (glibc 2.35 or newer, e.g. Ubuntu 22.04, SteamOS), OpenGL 3.3, a graphics card
of the last ten years; on the Steam Deck the graphics start at "Low" with at most 40 frames a second (set the
screen to 40 Hz in the Deck's quick menu; "Frugal (battery)" spares the battery more).

If the game crashes, a report is written to crashes/ in the save folder, and the title says so on the next start.
