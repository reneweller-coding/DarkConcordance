# Hinweise zur Steuerung, die jedes Level zeigen kann (Deutsch, die Quelle).
# "<schlüssel>.dorra": so gilt es für Dorra; "-" heißt: für sie nichts.

h_fire          = Schießen: rechter Trigger oder linke Maustaste. Das Gewehr nimmt das nächste Ziel vor dir.
h_fire.dorra    = Zuschlagen: rechter Trigger oder linke Maustaste. Halten schlägt die ganze Folge bis zum Überkopfschlag.
h_strafe        = Linker Trigger / Umschalt hält die Blickrichtung: zurückweichen und weiterfeuern.
h_strafe.dorra  = Linker Trigger / Umschalt: Schild hoch. Er hält Schüsse und Schläge von vorn ab.
h_bolt          = -
h_bolt.dorra    = B / F: Sprengbolzen werfen – für alles, was der Hammer nicht erreicht.
h_stim          = Q / Y: Stim injizieren (+40 Leben).
h_heat          = Das Gewehr ist überhitzt. Kurz absetzen.
